ML Machine Repair Quiz

Choose the best answer for each question. These questions ask you to apply the same repair logic from the game: diagnose the data signal, identify the target or goal, interpret the pattern clue, and choose a fitting starting method.

  1. Regression task with Linear Regression
  2. Classification task with Random Forest
  3. Clustering task with k-Means
  4. Dimensionality reduction task with PCA

  1. Predict a continuous numeric value from labeled examples.

  1. Logistic Regression
