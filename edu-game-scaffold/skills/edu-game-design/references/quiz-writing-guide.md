# Writing Playtester Quiz Questions

The quiz's job is to detect whether playing the game changed someone's
understanding of the target concept — not to test whether they can
recall a definition.

Note: the core quality criteria below are also included directly in the
prompt every student (scaffold or control) uses to kick off this step, so
that quiz quality doesn't vary by condition — only the game itself should
vary. This file is a more detailed elaboration for your own reference
while co-drafting, not an advantage exclusive to this condition.

## A good question requires applying the concept

Ask the player to predict a behavior, compare two outcomes, or spot what's
wrong with a claim — not just name a term.

**Weak (recall):** "What does LRU stand for?"

**Strong (application):** "A cache using LRU eviction just accessed
blocks A, B, C, A, D in that order with room for 3 blocks. Which block
gets evicted next, and why?"

The strong version can only be answered by someone who actually
understands how the policy behaves, not someone who memorized the
acronym.

## A good question has exactly one defensible correct answer

Avoid questions where two options could both be argued as correct
depending on interpretation. If a question needs a footnote to be fair,
rewrite it.

## A good question can't be guessed from general knowledge alone

If someone who has never played the game — but has some general
familiarity with the topic — could still answer correctly, the question
is testing prior knowledge, not what the game taught. Test questions
against this by imagining someone who knows the topic name but nothing
about the specific mechanic or misconception the game targets.

## Tie every question back to Phase 1

Each question should map to something specific from the learning
objective or misconception named earlier in the design process — not a
generic fact about the broader topic. If a question doesn't connect to
anything the student said they wanted a player to understand, cut it or
revise it until it does.

## Keep it focused

10 questions, multiple choice, answerable in about five minutes. This
quiz gets given twice (before and after play) to people who are also
playing several other games that day — length still matters, but with 10
questions there's more room to cover the concept from a few angles
without relying on any single question to carry the whole assessment.
